# Unit 1.1 Exercises: Java Threading Fundamentals

Master foundational Java multithreading in isolation:
1. **Exercise 1: Basic Thread Spawner with Lambda** - Create, name, start, and join worker threads using `Runnable` lambdas.
2. **Exercise 2: Parallel Computation Aggregator** - Run independent partial computations across multiple worker threads and aggregate results into a thread-safe structure.
3. **Exercise 3: Thread State Monitor** - Track and verify thread state transitions (`NEW`, `RUNNABLE`, `TIMED_WAITING`, `TERMINATED`).

### Running & Compiling
Compile and execute using `javac`:
```bash
javac exercises/ThreadingFundamentalsExercises.java
java -cp exercises ThreadingFundamentalsExercises
```

Or verify with solutions:
```bash
javac exercises/solutions/ThreadingFundamentalsSolutions.java
java -cp exercises/solutions ThreadingFundamentalsSolutions
```
