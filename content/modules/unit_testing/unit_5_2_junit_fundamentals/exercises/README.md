# Unit 5.2 Exercises: JUnit Fundamentals

## Overview
These exercises test your understanding of JUnit 5 test structuring and assertions:
- Lifecycle callbacks (`setUp` / `@BeforeEach` and `tearDown` / `@AfterEach`)
- Assertion parity (`assertEquals`, `assertTrue`, `assertThrows`)
- Testing insulin correction and carbohydrate ratio calculations

## How to Run the Exercises

### Compile and Run Starter Code:
```bash
javac -d .temp_bin content/modules/unit_testing/unit_5_2_junit_fundamentals/exercises/JUnitFundamentalsExercises.java
java -ea -cp .temp_bin JUnitFundamentalsExercises
```

### Compile and Run Reference Solution:
```bash
javac -d .temp_bin content/modules/unit_testing/unit_5_2_junit_fundamentals/exercises/solutions/JUnitFundamentalsSolutions.java
java -ea -cp .temp_bin JUnitFundamentalsSolutions
```
