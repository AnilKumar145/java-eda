# Unit 5.1 Exercises: Testing Fundamentals

## Overview
These exercises test your understanding of unit testing principles in Java:
- Applying the Arrange-Act-Assert (AAA) pattern
- Testing boundary conditions and clinical assertions
- Maintaining strict test isolation without shared mutable state

## How to Run the Exercises

### Compile and Run Starter Code:
```bash
javac -d .temp_bin content/modules/unit_testing/unit_5_1_testing_fundamentals/exercises/TestingFundamentalsExercises.java
java -ea -cp .temp_bin TestingFundamentalsExercises
```

### Compile and Run Reference Solution:
```bash
javac -d .temp_bin content/modules/unit_testing/unit_5_1_testing_fundamentals/exercises/solutions/TestingFundamentalsSolutions.java
java -ea -cp .temp_bin TestingFundamentalsSolutions
```
