# Unit 4.2 Exercises: JPA/Hibernate Persistence Context

## Overview
These exercises test your mastery of the JPA Persistence Context, entity state transitions (Transient, Managed, Detached, Removed), First-Level Cache identity map lookups, automatic dirty checking with SQL UPDATE generation, and JPQL parameter binding.

## How to Run the Exercises

### Compile and Run Student Starter Code:
```bash
javac -d .temp_bin content/modules/database_part_2/unit_4_2_jpa_persistence_context/exercises/JpaPersistenceContextExercises.java
java -ea -cp .temp_bin JpaPersistenceContextExercises
```

### Compile and Run Reference Solution:
```bash
javac -d .temp_bin content/modules/database_part_2/unit_4_2_jpa_persistence_context/exercises/solutions/JpaPersistenceContextSolutions.java
java -ea -cp .temp_bin JpaPersistenceContextSolutions
```
