# Java Application Labs Framework

---

## Overview
Application labs are enterprise scenario-based projects built around the healthcare domain. They challenge the learner to design real-world software components by combining multiple language and architectural features.

## Required Lab Assets
Each lab folder contains:
1. `README.md`: YAML frontmatter + Generic Information + Use Case + Rules + Test Cases.
2. `tasks.md`: Detailed step-by-step implementation instructions.
3. `StarterCode.java`: Starter Java classes with method stubs and clear TODO blocks.
4. `Tests.java` or `LabTest.java`: Verification test suite (e.g. JUnit 5 assertions).
5. `solution/Solution.java`: Production-grade reference implementation.
