# Java Exercises Framework

---

## Overview
Exercises are concept-focused coding challenges designed to practice and test specific Java concepts in isolation without domain narrative.

## Format & Structure
Each unit provides:
1. `README.md`: Explaining the 3 exercises and instructions.
2. Starter Java class or interface with TODO methods.
3. Test suite using JUnit 5 or plain `assert` statements verifying 3+ test cases per exercise.
4. Solution file with reference implementations.

## Quality Standards
- Pure algorithmic and language mechanics (e.g. extending Thread, implementing Runnable, synchronized blocks, wait/notify, ExecutorService).
- Independent, runnable, and verifiable via Maven or `javac`.
